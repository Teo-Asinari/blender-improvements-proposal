# Calipers roadmap

## Near-term UX

- Simplify the panel around one clearly identified active remesh context.
- Enable the Voxel Size Guide by default, while retaining an explicit toggle
  to hide it.
- Always label which value drives the guide: `Destructive Remesh Voxel Size`
  or `Modifier Voxel Size`.
- Collapse the inactive destructive/modifier workflow by default.
- Rename both voxel-size controls so their targets are unambiguous, and state
  that the destructive value has no visible effect until Voxel Remesh runs.
- Move risk thresholds and estimator tuning into a collapsed Advanced
  section.
- Replace or demote the ambiguous `Auto` guide-source selector in favor of
  explicit source controls.
